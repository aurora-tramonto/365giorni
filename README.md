# Dall'Aurora al Tramonto

Piano di lettura biblica: tre letture al giorno. Sito statico, senza account né server:
i dati restano nel browser di chi lo usa (con copie automatiche e backup su file).

## Pubblicare con GitHub Pages
1. Crea un repository pubblico su GitHub (es. `aurora-tramonto`).
2. Carica `index.html`, `icon.svg`, `manifest.webmanifest`.
3. Repository → Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
4. Dopo 1-2 minuti il sito è su `https://TUONOME.github.io/aurora-tramonto/`.

## Alternativa: Vercel / Netlify
Importa il repository (nessun build, nessuna variabile). Output directory: la radice.

## Importare i tuoi progressi
Nella versione attuale: scheda **Dati → Genera codice**, copialo. Sul nuovo sito: **Dati → Ripristina da codice**.

## Nota
I dati sono per browser e dispositivo: ricorda di fare ogni tanto il backup su file (scheda Dati).
